# React Task Manager

A simple Task Manager application built with React.js and Vite.

## Features

- Add new tasks
- Display tasks
- Mark tasks as Complete
- Undo completed tasks
- Delete tasks
- Prevent empty tasks
- Responsive design

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML
- CSS

## Components

- App
- Header
- TaskForm
- TaskList
- TaskItem

## Task Management

Users can add a new task using the input field.

Tasks can be marked as Complete or changed back using Undo.

Users can also delete tasks.

Empty tasks are not allowed.
